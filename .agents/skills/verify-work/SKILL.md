# Verify Work

Use this before claiming work is complete, fixed, ready, faster, or zero
overhead.

## Workflow

1. Identify the strongest available verification command or evidence.
2. Run targeted checks for changed contracts.
3. Run broader checks when the repository provides them.
4. Record exact commands and outcomes in the task, PR, or handoff.
5. If a check cannot run, state the concrete blocker and residual risk.

## Completion Rule

No completion or performance claim is valid without fresh evidence.
